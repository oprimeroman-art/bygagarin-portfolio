2. Какие данные обрабатываются

  • Текст обращения: выбранное направление, описание задачи, желаемый результат, а также любые сведения, которые пользователь сам включил в сообщение.
  • Данные отправителя: имя и адрес электронной почты, отображаемые при получении письма; имя профиля и имя пользователя Telegram, если обращение отправлено через мессенджер; иные контактные сведения, добровольно указанные в сообщении.
  • Переписка и вложения: содержание ответов и файлы, которые пользователь самостоятельно направил оператору.
  • Технические данные хостинга: при посещении GitHub Pages сам хостинг может регистрировать IP-адрес посетителя для обеспечения безопасности. Согласно документации GitHub, такие IP-адреса записываются и хранятся GitHub; оператор сайта не получает эти журналы через форму или интерфейс сайта. Подробнее — документация GitHub Pages и политика конфиденциальности GitHub.

Оператор не запрашивает через форму паспортные данные, сведения о здоровье, биометрические данные, банковские реквизиты или специальные категории персональных данных. Не включайте такие сведения в описание задачи. Не направляйте данные других людей без законного основания.

3. Как работает форма на сайте

Форма на сайте является генератором текста брифа. Выбранное направление, описание задачи и желаемый результат обрабатываются скриптом непосредственно в браузере пользователя. На сайте нет серверного обработчика формы, личного кабинета или базы заявок; заполненные поля автоматически оператору не отправляются.

После формирования брифа пользователь сам выбирает дальнейшее действие: открыть подготовленное письмо, скопировать текст и самостоятельно отправить его по электронной почте или вставить в Telegram. Передача оператору происходит только после самостоятельной отправки сообщения пользователем. До этого значения формы остаются в текущей странице браузера.

  • Исполнение обязанностей, установленных законодательством. Основание — соответствующие нормы законодательства Российской Федерации, в том числе при оформлении и исполнении договора и ведении обязательного учёта.

Данные не используются для автоматизированного принятия решений, создающих юридические последствия для пользователя, и не используются для рекламных рассылок без отдельного основания.

После получения сообщения оператор может получать, просматривать, систематизировать, уточнять, использовать, хранить, блокировать и удалять содержащиеся в нём персональные данные — только в объёме, необходимом для указанных целей.

6. Файлы cookie и локальное хранилище

В коде сайта byGagarin на дату редакции не используются файлы cookie, системы веб-аналитики, рекламные пиксели и инструменты поведенческого отслеживания. Поэтому отдельный баннер согласия на рекламные или аналитические cookie на сайте не устанавливается.

Для запоминания настройки доступности интерфейса — выбора уменьшенного движения — сайт использует локальное хранилище браузера (localStorage) с ключом gagarin-reduced-motion. Это значение хранится в браузере пользователя, не отправляется оператору и не используется для идентификации посетителя. Его можно удалить в настройках данных сайта в браузере.

Это описание не отменяет самостоятельную обработку технических данных хостинг-провайдером, указанную в разделе 2.

Технические журналы GitHub Pages хранятся самим GitHub в соответствии с его правилами и сроками; оператор сайта не управляет этими журналами.
