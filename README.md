# byGagarin — Роман Гагарин

**[Открыть опубликованный сайт](https://oprimeroman-art.github.io/bygagarin-portfolio/)**

Авторский сайт: маркетинг и PR, игры, программы, книги и публикации. Идеи, продуктовые решения и содержание — Романа Гагарина; разработка, исследование и проверки выполняются вместе с ИИ.

Сайт состоит из обычных HTML, CSS и JavaScript. Для публикации не нужны Node-сервер, база данных, регистрация или сборщик.

## Структура

| Путь | Назначение |
|---|---|
| `index.html` | Главная, избранные проекты, описание подхода и контакт |
| `projects/<slug>/index.html` | Страницы работ, ссылки на запуски и материалы |
| `experience/`, `services/`, `tools/` | Биография, направления работы и инструменты |
| `books/`, `publications/`, `archive/` | Книги, статьи, интервью и ранние проекты |
| `plain/index.html` | Полная текстовая версия без JavaScript и графики |
| `assets/site.css`, `assets/basic.css` | Принятый дизайн и базовое оформление старых браузеров |
| `assets/site.js` | Навигация, поиск, вкладки, фильтры, описание задачи, калькулятор |
| `assets/motion.js`, `assets/interactions.js` | Общий планировщик движения и реакции существующих элементов |
| `assets/materia.js`, `assets/materia.frag` | Необязательная WebGL-графика, адаптивное разрешение и статическая замена |
| `assets/images/`, `assets/fonts/` | Изображения, портрет и локальные Onest / Cormorant Garamond |
| `scripts/` | Генерация поиска и текстовой версии; проверка ссылок и метаданных |
| `docs/` | История дизайна, редакционное исследование и результаты проверки |

Старые адреса `/about/` и `/prototype/` сохранены как переходы. Исторические версии остаются в Git. Действующие страницы используют один набор стилей и общие скрипты; каталогов `v3`, `v4`, `v5` больше нет.

## Локальный запуск

Из родительской папки, в которой каталог проекта называется `bygagarin-portfolio`:

```sh
python -m http.server 8000
```

Открыть `http://localhost:8000/bygagarin-portfolio/`. Сайт использует тот же префикс пути, что GitHub Pages.

После правки текста или добавления страницы:

```sh
python scripts/build_catalog.py
python scripts/check_site.py
```

Генератор обновляет поиск и текстовую версию. Проверка использует стандартную библиотеку Python и установленный Node.js для проверки синтаксиса JavaScript. В опубликованном сайте эти инструменты не нужны.

## Движение и совместимость

Движение учитывает системную настройку `prefers-reduced-motion`; его также можно отключить кнопкой внизу страницы. Выбор запоминается только локально. Планировщик не рисует скрытые и находящиеся вне экрана сцены. WebGL запускается при приближении к объекту; разрешение зависит от размера canvas, DPR и скорости отрисовки.

Графика не нужна для чтения и переходов. При потере WebGL-контекста возвращается статическая форма, при восстановлении создаётся новый рендерер. Параметр `?graphics=off` включает эту же статическую ветку для проверки.

В браузерах без CSS Grid остаётся базовое оформление; для старого оборудования есть [текстовая версия](https://oprimeroman-art.github.io/bygagarin-portfolio/plain/). Она не использует скрипты, внешние шрифты, изображения и современные CSS-функции. Работа HTTPS на Windows XP зависит от браузера, TLS и сертификатов; испытания на XP не проводились.
