# byGagarin — персональное портфолио

Статический сайт Романа Гагарина (Романа Олеговича Наберушкина), вдохновлённый **структурой** портфолио [bot-x.ru](https://bot-x.ru/). Не содержит чужого кода, логотипов, текстов или цен.

## Содержание
- Проекты: интерактивные карточки, категории, поиск и подробный просмотр.
- Снимки настоящих страниц All Indie, SNG Games, Panorama Studio и игр через внешний сервис WordPress mShots (изображения подгружаются клиентом).
- Основные направления деятельности, профессиональная хронология, четыре книги, архив работ, ссылки и FAQ.
- Schema.org Person и адаптивная мобильная версия.

## Запуск

Открыть `index.html` в браузере. Сборка и зависимости не требуются. GitHub Pages может публиковать содержимое этой ветки из корня `/`.

## Источники иллюстраций

Превью — автоматические скриншоты адресов проектов, создаваемые WordPress mShots:
`https://s.wordpress.com/mshots/v1/{url}?w=1440`.
Если скриншот недоступен, показывается встроенная текстовая подложка. Файлы скриншотов **не хранятся** в репозитории; при первой загрузке требуется сеть, а mShots может показывать кэшированные версии.
