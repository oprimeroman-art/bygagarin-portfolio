# byGagarin — персональное портфолио

Статический сайт Романа Гагарина / byGagarin. Публикация: GitHub Pages из ветки `site/portfolio-botx`.

## Структура
- `index.html` — главная страница с поиском, фильтрами и ссылками на кейсы.
- `projects/index.html` — полный каталог из 41 карточек.
- `projects/<slug>/index.html` — отдельная страница каждого проекта.
- `experience/` — профессиональная хронология по резюме от 10.11.2025.
- `books/` — книги и отдельные страницы.
- `publications/` — статьи и интервью с датами.
- `archive/` — старые клиентские работы и профили.
- `timeline/` — общая хронология.
- `sources/` — источники и методика дат.
- `links/` — единый список публичных ссылок.
- `sitemap.xml`, `robots.txt`, `favicon.svg`, `.nojekyll`, `404.html` — базовая SEO-инфраструктура и обработка ошибок.

## Даты
- Периоды работы взяты из резюме, обновлённого 10.11.2025.
- Годы книг взяты из биографической страницы автора.
- Даты публикаций проверяются по страницам DTF, DEV и SoundStream.
- Даты репозиториев взяты из GitHub metadata и не трактуются как начало разработки.
- Для каталожных проектов без опубликованной даты релиза указывается дата снимка каталога `16.11.2026` и прямо отмечается, что дата релиза неизвестна.

## Изображения и ссылки
- Для 33 карточек All Indie используются исходные URL обложек с `all-indi.ru/assets/` и исходные страницы проекта/запуска.
- Для платформ и отдельных проектов без исходной обложки используется снимок публичной страницы через внешний сервис миниатюр; оригинальные ссылки доступны отдельно.
- Личные телефон и электронная почта из резюме в сайт не перенесены.

## Обновление
Изменения вносятся в отдельную ветку `site/portfolio-botx`; `main` не затрагивается.
