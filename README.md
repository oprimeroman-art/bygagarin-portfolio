# Роман Гагарин — byGagarin

Личное портфолио: маркетинг, PR, цифровые продукты, игры, книги и публикации.

Публичный сайт: https://oprimeroman-art.github.io/bygagarin-portfolio/

## Публичная структура
- `index.html` — главная витрина с избранными проектами, ключевым опытом, тремя книгами и отобранными публикациями.
- `projects/index.html` — дополнительные проекты.
- `projects/emperors-own/index.html` — подробный кейс Volga Studios / Kickstarter.
- `archive/index.html` — ранний профессиональный опыт и первые проекты.
- Остальные страницы проектов — справочные страницы для выбранных работ.

## Редакционный принцип
Главная показывает то, чем автор хочет представляться сейчас. Ранние работы вынесены в архив. Публичные ссылки ведут на конкретные проекты, материалы и источники, а не на полный перечень личных профилей.

Даты указываются только при наличии резюме, публикации или архивной записи. Kickstarter pledges не называются полученной выручкой. Оценка рекламного бюджета в кейсе The Emperor's Own обозначена как воспоминание автора, а не как публично подтверждённая сумма.
