# byGagarin / Архитектура авторского бюро (v4)

Дата: ноябрь 2026. Ветка: site/portfolio-botx. Публикация: GitHub Pages.

## Структура
- `/` — портал-картотека, а не длинный продающий лендинг
- `/services/` — конкретные проблемы и решения
- `/projects/` — фильтруемый каталог реальных работ
- `/experience/` — биография и хронология с первоисточниками
- `/tools/` — рабочие продукты и калькулятор
- `/publications/`, `/books/`, `/archive/` — библиотека и архив
- `/projects/<slug>/` — индивидуальные кейс-файлы с источниками

## Собственные анимации и интерактив
- Кинетические заголовки, pointer-responsive стек проектов и сетевой canvas в первом экране
- Командный поиск (`/`, Ctrl+K / Cmd+K), навигация по всему сайту
- Hover preview разделов, переключатель реальных кейсов
- Переходы между страницами, mobile overlay, адаптивная верстка
- Фильтры работ и конструктор брифа (без отправки на сервер)
- Reduced motion учитывается; анимация не должна блокировать контент

## Источники
Исторические факты, даты и цифры не подменяются. Все предыдущие страницы и внешние ссылки сохранены по смыслу; текстовые материалы берутся из существующего портфолио. Скриншоты и обложки — из авторского сайта/действующих проектов.

## Ограничения
GitHub Pages — статический хостинг: заявки через форму не отправляются автоматически. Бриф копируется локально. Удалять архив или публикации без команды владельца нельзя.
