# Проверка byGagarin · 17 ноября 2026

Исходная опубликованная версия: `cd23ab293efc75f0cd8b894b6b985d8dfff097af`, ветка `site/portfolio-botx`.

## Реализовано

- Сохранены композиция, шрифты Onest / Cormorant Garamond, палитра SNG Games, портрет, навигация и переход Gagarin.
- Удалена верхняя материя. Карточки обложки открывают HTML-страницы работ.
- Нижняя материя встроена без прямоугольной сцены, фона, сетки, рамок и технических уголков. Сохранены три состояния, отклик, импульс и пауза; добавлено управление с клавиатуры.
- Размер canvas рассчитывается по CSS-размеру и DPR; есть ограничение площади и снижение разрешения при медленных кадрах. WebGL загружается только при приближении к сцене.
- Планировщик останавливает вычисления вне экрана, в скрытой вкладке и при уменьшении движения. Точка заголовка использует пружинное движение только во время взаимодействия.
- Поиск включает все 26 содержательных страниц и их текст. Добавлены переключение вкладок стрелками, управление фокусом диалогов, доступное закрытие меню и сброс перехода после возврата назад.
- Проведена редактура всех содержательных страниц. Собственные сведения о работе отделены от публикаций; ссылки на прежний HTML как на доказательство удалены. Точные страницы книг, статей и документов сохранены.
- В биографию добавлена связь между прежней работой и нынешними проектами. Коротко описано соавторство с ИИ.
- Один общий набор стилей и скриптов; старые поколения удалены из рабочего дерева. Исследовательские и дизайнерские документы перенесены в `docs/`, история Git сохранена.
- Шрифты обслуживаются с сайта, повторные тяжёлые изображения заменены уже существующими облегчёнными версиями. Для социальных предпросмотров доступен JPEG-портрет.
- Обновлены описания, Open Graph, канонические адреса и применимая структурированная разметка. 404 исключена из индекса; старые адреса сохранены.
- Полная текстовая версия работает без скриптов, WebGL, загрузки шрифтов и изображений. Основной документ сохраняет навигацию без JavaScript.

## Проверки

`python scripts/build_catalog.py` и `python scripts/check_site.py` выполнены без ошибок. Проверяются все 30 HTML-документов, ссылки на страницы и ресурсы, якоря, дубли ID, H1, title/description, canonical, JSON-LD, sitemap и синтаксис JavaScript.

Адаптивная проверка в Chromium: 27 основных страниц × 7 размеров — **189 комбинаций**.

Использовались настоящие размеры вложенного viewport в Chromium; это проверка адаптивного CSS, а не испытание физических устройств.

Проверены вручную: мобильное меню, поиск Forge и «Двигать инди», открытие результата Enter, переключение проектов мышью и стрелками, фильтр игр (четыре карточки), формирование описания задачи, включение и выключение уменьшенного движения. Для калькулятора: бюджет 12 000 ₽, 24 заявки, 6 продаж, 48 000 ₽ выручки дают 500 ₽ / 2 000 ₽ / 4×.

Дополнительно все 27 основных страниц проверены на ширине 390 px с запрещённым выполнением JavaScript: переполнений, пропавших изображений и пропущенных H1 нет. Основные разделы доступны через HTML-навигацию.

Доступный облачный Chromium не создаёт WebGL-контекст. На нём проверена статическая ветка и доступность остального интерфейса. Шейдер отдельно скомпилирован и отрисован в трёх режимах в OpenGL ES Mesa/llvmpipe на 720×600: в каждом есть непрозрачная геометрия и полностью прозрачный фон. Это программная проверка GLSL, не аппаратное испытание WebGL в Safari.

Ошибок приложения при проверенных действиях не обнаружено. Сообщения расширения среды `chrome-extension://…` в этот результат не включались.

## Источники

Прямые страницы All Indie, издательские карточки, статьи DTF / vc.ru / DEV, Steam, Kickstarter / Kicktraq, интервью и файлы проектов проверены отдельно. Свежие ссылки README и Studio возвращают HTTP 200. Данные книг дополнительно проверены через веб-доступ к Ridero.

- Часть социальных страниц отдаёт служебную заглушку этому клиенту; их адреса совпадают с опубликованными ссылками авторской площадки. Доступ для посетителя не сертифицирован.
- Planeta.ru запрашивает проверку доступа; числовые результаты «Оператора 911» взяты из конкретной авторской статьи, не из недоступного архива.
- Ridero периодически вернул 503 прямому HTTP-клиенту; все три издательские карточки удалось прочитать через веб-инструмент.
- Недоступная анкета Специалисты.рф убрана из навигационных ссылок; соответствующий опыт остаётся со ссылкой на точную доступную анкету Specfinder.
- Исторический источник с прежним HTML портфолио хранится в исследовательских заметках, но не выдаётся посетителям за независимое доказательство.
