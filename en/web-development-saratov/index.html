01 / What I build

Not just a page.
A working tool.

I build websites in Saratov and for clients in other regions. It can be a small site, a large catalog or a standalone web service. I don't overcomplicate a system for the sake of elegant architecture: what matters most is that it solves the problem.

01
Websites · Structure · SEO

A site should explain, be found and work

I design the structure and navigation, and build the pages, content and interface. I account for mobile devices, accessibility, speed and search engine requirements.

  • Company websites and personal portfolios
  • Catalogs, project and publication sections
  • Semantic structure, metadata and internal linking
  • Contact forms and user flows
Result: a published site with a clear structure, working navigation and an SEO foundation.
02
WordPress · APIs · Integrations

When a ready-made platform isn't enough

I improve existing websites and build small tools for specific processes. I use ready-made solutions where they fit and write custom code where it is justified.

  • WordPress improvements and small plugins
  • Service integrations and APIs
  • Search, filtering, catalogs and forms
  • Automation of repetitive actions and editorial processes
Result: a site or tool that solves a specific work task.
03
Interactive · 360° · WebGL

Web products you can interact with

I build browser games, interactive graphics and tools for 360° spaces. These are not just presentation effects: such projects have state, logic, events and a user flow.

  • Interactive 360° scenes and virtual tours
  • Browser games and prototypes
  • Generative graphics and WebGL experiments
  • Exports and standalone web versions
Result: a working interactive product you can open and check.

From the brief

I have no interest in building complex architecture just because I can. If a task can be solved more simply and reliably, I choose the simpler approach. Results first, technology second.

Users, scenarios, constraints, content and acceptance criteria.

02
