Purpose

Forge came out of a specific problem: standard 360° panoramas were limiting scene quality. I built a tool that checks the 2:1 aspect ratio, changes resolution, and works with the image seam. It's built on Python, Pillow, and NumPy, and Real-ESRGAN can be plugged in for upscaling.

Public core of Panorama Forge

Connection to Tihaya Voda

On November 1, 2026, I documented how I integrated the Forge 0.1 core into the production of Tihaya Voda: after processing, a panorama is split into fragments and assembled in the game scene.

Integration documentation · 01.11.2026

Role and origin of the code

I set the requirements for the tool and decide what the game needs. I write the code, build, and checks together with Codex. I kept the source code and the materials history in the Tihaya Voda README.

Game README ↗Source code

Verified scope

Forge 0.1 is available as a local Windows package with a browser interface (in Russian). Download and extract the ZIP, then run START_WINDOWS.bat. Python 3.11+ is required; dependencies are installed on first launch. Precision mode works locally. AI reconstruction requires the separate INSTALL_AI_WINDOWS.bat setup and a Vulkan-compatible GPU. A full 8K GPU run has not been verified.
