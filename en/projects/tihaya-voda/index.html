About the project

I'm making «Tihaya Voda» as a large Arctic horror, not a short demo. A polar station, exploration of the territory, documents, sound, story discoveries, tasks and several endings.

  • There is a browser version you can try.
  • The source code and development history are in an open repository.
  • Plot, quests, interactive scenes and graphics — I'm still working on all of it.
